# ⚽ 足球预测工具

这是一个基于 **泊松分布 (Poisson Distribution)** 算法的简易足球比赛预测工具。它通过分析两支球队的历史平均进球数，利用数学模型预测比赛的主胜、平局和客胜概率。

## 🚀 核心功能

-   **数据加载**：自动读取球队的历史进球数据（模拟数据或真实数据）。
-   **概率计算**：使用泊松分布公式计算特定比分出现的概率。
-   **结果预测**：汇总所有可能比分的概率，输出主胜、平局、客胜的百分比。

## 📂 项目结构

-   `main.py`: 程序的入口文件，负责调用预测逻辑并展示结果。
-   `predictor.py`: 核心算法模块，包含泊松分布计算公式及胜负平概率统计逻辑。
-   `data_loader.py`: 数据加载模块，负责读取和处理球队数据。

## 📈 算法原理简述

本项目采用经典的泊松分布模型：
$$P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$$
其中 $\lambda$ 代表球队的平均进球期望值，$k$ 代表具体的进球数。通过计算双方在不同进球数下的概率乘积，得出各种比分的可能性。
